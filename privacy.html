CRM Backups Privacy Policy

Effective date: 8 October 2026

Scope and operator

This policy describes the private CRM Backups application operated by the owner of the crm-backup-info GitHub repository. It applies to the operator’s authorized Google Drive connection and backup workflow.

Information accessed and stored

The application accesses Google Drive file contents and metadata as needed to upload, list, verify, restore and manage encrypted backup files. Its OAuth permission permits access to all files in the authorized Drive account, although the intended use is a designated backup folder. Backup sources may include CRM databases, attachments, configuration and application recovery files.

Use and protection

Data is used to create and maintain backups and restore the operator’s systems. Restic encrypts backup content before upload to Google Drive. OAuth tokens and backup credentials are stored on the operator’s server with restricted file permissions. The operator retains responsibility for server security and safe storage of recovery credentials.

Sharing

The application does not sell data, use it for advertising or use it to train AI models. Encrypted backups and the metadata needed to store them are transmitted to Google Drive. Google processes account and service information under its own privacy policy. This public GitHub Pages website contains no backup data or credentials.

Retention and deletion

Backups remain in the authorized Google Drive account until removed by the operator or by a configured retention policy. No fixed retention period is promised by this policy. Revoking OAuth access stops future authorized access but does not automatically delete existing backups. The operator can remove stored backups from Google Drive and local backup copies from the server.

Control and revocation

The operator can revoke the application’s access in the Google Account third-party connections settings. Backup restoration requires the relevant encryption password. This application is for private use and does not accept public users.

Website hosting

This informational site uses no custom analytics, advertising scripts or forms. GitHub Pages may process technical access information under GitHub’s privacy policy.

Contact and changes

For non-sensitive privacy questions, use the repository’s issue tracker. Do not include confidential information. Updates to this policy will be published here with a revised effective date.
