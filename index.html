PRIVATE BACKUP UTILITY

CRM Backups

Encrypted backups for the operator’s self-hosted CRM systems.

Purpose

CRM Backups is a private application operated by the owner of this GitHub repository. It uses rclone and restic on an Ubuntu server to store encrypted database exports, uploaded files, configuration and application recovery files in the operator’s Google Drive account.

Google Drive access

The operator authorizes Google Drive access through Google OAuth. The application requests Drive access to create, list, read, update and remove backup files as needed for backup, verification, retention and restoration. The requested permission technically allows access to all files in the authorized Drive; the intended workflow is limited to the designated backup folder.

This utility is for the operator’s own use. It does not offer public registration or ask visitors to connect their Google accounts. This website contains information only and does not host CRM records or credentials.
